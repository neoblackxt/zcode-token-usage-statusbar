description: 显式安装/更新本机 ZCode 悬浮用量状态条（修改 app.asar，完全退出并重开生效；clean 分叉唯一安装入口）
---
把 zcode-token-usage-statusbar（clean 分叉）的悬浮状态条安装到本机 ZCode 桌面客户端。clean 分叉不会自动安装——本命令是唯一的安装/修复入口。

执行：用 Bash 运行安装器（插件根目录 = 本命令文件所在目录的上一级）：

    python3 "<插件根目录>/overlay_install.py" install

Windows 上 `python3` 可能是 Microsoft Store 存根（静默失败），依次改用 `python`、`py -3`；macOS/Linux 用 `python3`。安装器（patch_install/monitor）打印的手动命令已带真实解释器绝对路径，照抄最稳。

结果处理（按以下优先级，不能仅凭退出码为 0 判断需要重启）：

- 失败、待收尾或输出安装/更新尚未完成、记录无法确认的提醒：优先转述实际输出，不得宣称安装成功或仅重启即可修复。
- 输出插件重启提醒：优先于「已安装，注入行已指向当前目录」。用一句普通句子说明"需完全退出 ZCode（所有窗口：菜单「退出」）并重新打开，窗口底部的状态条才会加载新版；只关窗口/刷新/重开会话无效"。**不要用引用块、加粗、横幅或emoji把提醒复刻成醒目公告**（clean 分叉不把模型回复当公告通道——上游此格式会被宿主渲染成红色警示横幅，正是用户分叉要消灭的形态）；重启提醒的常驻载体是状态条 ⚙ 齿轮红点与「插件更新」分区，安装器的原始输出也已在命令结果中展示。安装器可能弹出监控窗口，确认生效后会自动关闭，属正常现象。
- 仅输出「已安装，注入行已指向当前目录」，且没有待加载/待修复提醒：只表示无需重新注入；此时才可回复无需操作。若安装器已确认加载且无提醒，也不要额外要求重启。
- 失败：把安装器输出原样转述。权限不足时按平台处理：Windows（Program Files 等受保护位置，报 Errno 13/拒绝访问）以管理员身份打开终端（右键终端图标 →「以管理员身份运行」）重跑同一条命令；macOS/Linux（/opt 等系统位置）按提示建议 `sudo env HOME="$HOME" PATH="$PATH" python3 "<插件根目录>/overlay_install.py" install`（sudo 默认重置 HOME/PATH，会让运行目录定位失败，必须保留）。
- 若输出「运行中替换失败 / 待收尾」：说明完全退出 ZCode 后重跑同一条命令，或等监控窗口自动收尾。

补充说明（用户问起时再展开，不必每次输出）：

- 卸载：`/uninstall-overlay`（剥注入行、剥渲染桥，clean 分叉还会还原引擎自动压缩补丁并清理备份）。
- clean 分叉不自动安装、不自动补桥：SessionStart 只同步运行时文件；一切客户端修改（app.asar 注入行、渲染桥、引擎补丁）都只经本命令或 ⚙ 面板显式动作触发。
- 待重启才由状态条 ⚙ 齿轮红点提醒（点进 ⚙ 面板「插件更新」分区后消失，该分区有「重启 ZCode」按钮与「已更新成功，点击重启 ZCode 即可生效」提示条）；更新成功且无需重启（浮层已自动热重载）、或仅有新版尚未安装时不亮红点。会话内不注入任何文字提醒，本命令的命令行提醒输出保留。
- 该安装只影响桌面客户端；SSH 远程会话、Web 版与本插件无关。
